How this page is built

  1. Flow engine as *.flow
  2. /
  3. MLIR flow.transpiler --mlir --llvm
  4. /
  5. emcc gfx_wasm runtime
  6. /
  7. WASM this tab

The Flow IR compiles at -O1 through MLIR to LLVM IR, then links with emcc at -O1. The C backend is used for native macOS builds. Both backends produce byte-identical output. Epic #221 tracks MLIR WASM parity.
